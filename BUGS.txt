Bugs found in the starter code and their fixes

1. testbed_description/CMakeLists.txt
   ament_package was missing its parentheses, so the package could not be built.
   Fix: changed to ament_package().

2. testbed_bringup/maps/testbed_world.yaml
   The image entry pointed to a non-existent file (wrong_path_testbed_world.pgm).
   Fix: pointed it to testbed_world.pgm.

3. testbed_bringup/CMakeLists.txt
   The maps directory was not installed, so the map was missing from the install space.
   Fix: added maps to the install(DIRECTORY ...) rule.

4. testbed_gazebo/CMakeLists.txt
   The models directory was not installed, although the launch file adds it to GAZEBO_MODEL_PATH.
   Fix: added models to the install(DIRECTORY ...) rule.

5. testbed_description/launch/robot_description.launch.py
   robot_state_publisher did not use simulation time, unlike the RViz node in the bringup launch file.
   Fix: added the use_sim_time parameter.

6. testbed_description/urdf/testbed.gazebo
   Stray extra ">" after the initial_orientation_as_reference tag in the IMU plugin.
   Fix: removed it.

7. testbed_description/urdf/testbed.gazebo
   The lidar maximum range was 1.5 m, so from the spawn point in a 20 m map every beam returned inf and the scan was empty. This left AMCL with no data to localize against.
   Fix: raised the sensor range max to 10.0 m and set laser_max_range in the AMCL parameters to match.
